# 🐝 CBee Panel

پنل مدیریت حرفه‌ای پروتکل‌های V2Ray/Xray با قابلیت رله

## ✨ ویژگی‌ها
- پشتیبانی از پروتکل‌های **VLESS**, **VMess**, **Trojan**, **Shadowsocks**, **SOCKS**, **HTTP**, **HTTPS**, **gRPC**, **QUIC**
- روش‌های انتقال **WebSocket**, **XHTTP**, **gRPC**, **TCP**, **QUIC**
- پشتیبانی از **TLS** برای امنیت بیشتر
- مدیریت کاربران و رسیلرها
- ذخیره‌سازی در **JSON** محلی و **GitHub**
- داشبورد لحظه‌ای با آمار
- ربات **تلگرام** با دستورات کامل
- تم **زنبوری** حرفه‌ای
- دیپلوی آسان روی **Railway** و **Render**

## 🚀 نصب و اجرا

### روی Railway
1. ریپازیتوری را به گیت‌هاب آپلود کنید.
2. در Railway، پروژه را از گیت‌هاب ایمپورت کنید.
3. متغیرهای محیطی را تنظیم کنید.
4. دیپلوی خودکار انجام می‌شود.

### متغیرهای محیطی
| متغیر | توضیح |
|-------|-------|
| `SECRET_KEY` | کلید امنیتی |
| `GITHUB_TOKEN` | توکن گیت‌هاب برای ذخیره‌سازی |
| `GITHUB_REPO` | ریپازیتوری گیت‌هاب |
| `TELEGRAM_BOT_TOKEN` | توکن ربات تلگرام |
| `TELEGRAM_ADMIN_ID` | آیدی ادمین تلگرام |
| `ADMIN_PASSWORD` | رمز پیش‌فرض ادمین |
